## 指導手冊 — 軟體教學 — 系統操作

- **目的說明**: 本章說明軟體運行前的系統需求、安裝、啟動、掃描流程與常見排錯，確保使用者能順利開始掃描與重建工作流程。
- **系統需求**:
	- **作業系統**: Windows 10 或更新版本（64-bit）。
	- **Python**: 3.8+（建議 3.10）。
	- **套件**: 依 `requirements.txt` 安裝所有依賴。
	- **硬體**: 可連接的 ESP32-CAM 或相容相機、可控制步進馬達的 Arduino 電路、至少 8GB RAM、充足磁碟空間（建議 >10GB）。

- **安裝步驟**:
	- **環境準備**: 安裝 Python，推薦建立虛擬環境：`python -m venv venv` → `venv\Scripts\activate`。
	- **安裝依賴**: 在虛擬環境中執行 `pip install -r requirements.txt`。
	- **韌體/硬體**: 若使用 ESP32-CAM 或 Arduino，請先上傳該硬體範例程式（參考 `Arduino hardware programming program` 資料夾）。
	- **檔案結構確認**: 確認 `scan_images/`、`assets/` 等資料夾存在並有寫入權限。

- **啟動與執行**:
	- **啟動主介面**: 執行 `python main_ui.py`（若專案使用此檔作為入口）。
	- **CLI 工具**: 常用命令範例：
		- 生成 PLY：`python build_ply.py --input ./scan_images --output scan.ply`
		- 重建模型：`python reconstruct_simple.py --input scan.ply --output mesh.obj`

- **工作流程（步驟化）**:
	1. 檢查硬體連線（相機供電、USB/串列連線、步進馬達驅動）。
	2. 啟動相機捕捉服務（參考 `esp32_cam_capture.py`）。
	3. 在 UI 上執行「開始掃描」，或手動觸發相機拍照並把影像存至 `scan_images/`。
	4. 使用 `build_ply.py` 或在 UI 中呼叫「生成點雲/PLY」。
	5. 執行模型重建（`reconstruct_simple.py`），檢視結果（`view_ply.py`）。
	6. 如需整合成最終檔案，輸出 OBJ/STL 等格式並檢查完整性。

- **備份與檔案管理**:
	- 建議每次掃描建立新資料夾（格式如 `scan_YYYYMMDD_HHMM`），將原始影像、點雲、重建模型分別存放。
	- 定期備份 `scan_images/` 與 `assets/`。

- **常見問題與排錯**:
	- **無法啟動 UI**: 檢查 Python 版本與虛擬環境是否啟動，檢視錯誤訊息並安裝缺失套件。
	- **相機無回應**: 驗證相機電源、網路（若用 Wi-Fi）、固件是否正確上傳；重啟相機模組。
	- **影像存取錯誤**: 確認 `scan_images/` 權限與磁碟空間。
	- **點雲生成失敗**: 檢查輸入影像是否完整且曝光一致，減少模糊或重複影像。
	- **重建模型有洞或雜訊**: 調整重建參數（如密度、平滑化），或補拍缺少角度的影像。

- **安全與注意事項**:
	- 確保硬體電源正確並有適當散熱。
	- 操作步進馬達時避免手動干涉運動軌跡以防絞損。

- **附錄 — 常用命令速查**:
	- 啟動 UI: `python main_ui.py`
	- 捕捉影像（範例）: `python esp32_cam_capture.py --ip 192.168.x.x --count 36`
	- 建構 PLY: `python build_ply.py --input scan_images --output result.ply`
	- 重建 mesh: `python reconstruct_simple.py --input result.ply --output mesh.obj`

## 指導手冊 — 軟體教學 — 介面功能

- **目的說明**: 本章逐項解說軟體介面各元件功能、參數意義、使用範例與快捷操作，幫助使用者熟練操作。

- **主視窗總覽**:
	- **標題列/選單列**: 包含 `檔案`、`設定`、`幫助` 等常用選單。
	- **工具列（Toolbar）**: 快速按鈕（開始掃描、暫停、儲存、匯出、重建）。
	- **側邊欄（Sidebar）**: 專案管理、影像列表、參數設定面板。
	- **主顯示區（Canvas/Preview）**: 實時預覽相機畫面或已載入的點雲/模型。
	- **狀態列（Status Bar）**: 顯示連線狀態、進度百分比、目前檔案位置。

- **主要功能按鈕與面板說明**:
	- **開始掃描 / 停止**: 開始自動輪拍或停止拍攝。點擊 `開始` 後按鈕變為 `停止`，狀態列顯示進度。
	- **手動拍照**: 在預覽畫面下可點選「拍照」按鈕來逐張儲存影像。
	- **影像檢視器**: 顯示 `scan_images/` 中的影像縮圖，點選可放大預覽與刪除單張影像。
	- **生成點雲/PLY**: 在參數面板設定對齊、重建與輸出選項後執行。常見參數：影像來源資料夾、相機內參、輸出檔名。
	- **重建參數**: 包含稀疏/稠密重建選項、深度/密度閾值、表面平滑化程度。預設值提供「快速」與「高品質」兩種模式。
	- **匯出/儲存**: 支援匯出 PLY、OBJ、STL。匯出時顯示進度並提示輸出路徑。

- **設定面板詳述**:
	- **相機設定**: 曝光、解析度、白平衡、IP/COM 設定（視接入方式）。
	- **掃描策略**: 拍攝張數、每步角度（若有馬達控制）、是否自動曝光鎖定。
	- **輸出選項**: 檔案格式、精度、是否保留中間檔（點雲、暫存）。
	- **進階**: 日誌等級（DEBUG/INFO/ERROR）、並行處理執行緒數量。

- **常用操作範例**:
	- **快速掃描（預設）**: 開啟主畫面 → 選擇相機 → 選「快速」模式 → `開始掃描` → 等待完成 → `生成點雲` → `重建` → `匯出 OBJ`。
	- **高品質掃描**: 調整曝光與解析度、設定更多拍攝角度、選擇「高品質」重建，並增加重建密度參數。

- **快捷鍵一覽**:
	- **`Space`**: 開始/停止掃描
	- **`S`**: 手動拍照（Save）
	- **`G`**: 生成點雲（Generate）
	- **`R`**: 開始重建（Reconstruct）
	- **`Ctrl+E`**: 匯出當前模型

- **提示與最佳實務**:
	- 在拍攝前先鎖定曝光以保持影像一致性。
	- 使用三腳架或固定裝置避免相機震動。
	- 若模型邊緣缺失，補拍該角度並重新生成點雲。
	- 定期清理影像暫存與日誌以免磁碟爆滿。

- **錯誤提示說明（UI 顯示訊息）**:
	- **「相機未連線」**: 檢查相機 IP/COM、重新連線。
	- **「儲存失敗」**: 檢查磁碟空間與檔案權限。
	- **「重建失敗：參數不收斂」**: 降低重建密度或切換到「快速」模式後重試。

- **使用者案例 Q&A**:
	- Q: 如何只匯出部分模型？ A: 在預覽中裁切或指定欲匯出之群組，再使用 `匯出選定範圍`。
	- Q: 如何提高細節？ A: 提高影像解析度、增加拍攝角度與使用「高品質」重建設定。
